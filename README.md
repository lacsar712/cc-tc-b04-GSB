# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 邻断面对照

值班要对照相邻桩号谁挤得更狠：从页眉「邻断面对照」进专页。上排选左右两个桩号和截止时刻，中排列出两侧最近办结值与差值，下排写口径。

- 中排的数只来自接口重算（`POST /api/compare/recalc`），选定条件一变就作废旧数并重新重算，不临时填数。
- 任一侧在截止时刻前没有已办结记录时，该侧与差值一律留空，不出假数。
- 截止时刻之外的测点本次不算；重算与截止时刻必须一起提交，缺一边接口返回 400。
- 测量员可选桩号报送重算；巡检岗只读，不能报送（接口返回 403）。

口径：每侧取该桩号在截止时刻（含）之前最近一条已办结记录的收敛值；差值 = 左侧收敛 − 右侧收敛（mm）；谁挤得更狠按绝对值判定。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
